# הקמת בוט הטלגרם

הבוט: שולחים לו הודעה עם קישורי משרות (או מעבירים אליו הודעה מקבוצה), והוא עונה כמה משרות קיבל,
ואחר כך שולח ציון לכל משרה כשהניתוח מסתיים. הקוד: `src/services/telegram.py`,
`src/routes/telegram_routes.py`, והחלק המשותף עם וואטסאפ ב-`src/services/bot_intake.py`.

בכל מקום כאן `<service>` הוא שם השירות שלך ב-Render (ה-URL מופיע בראש עמוד השירות).

## 1. יצירת הבוט (דקה)
1. בטלגרם פותחים שיחה עם **@BotFather** (עם וי כחול) ושולחים `/newbot`.
2. בוחרים שם, ואחריו שם משתמש שמסתיים ב-`bot` (למשל `my_jobmatch_bot`).
3. BotFather מחזיר **טוקן** בצורה `123456789:AA...`. זה הסוד של הבוט: לא מדביקים אותו בצ'אט
   ולא בקבצים בריפו.

## 2. Render: הפעלה
1. השירות `jobmatch` ← **Environment** ← **Edit** ← מוסיפים:

   | Key | Value |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | הטוקן מ-BotFather |

2. **Save, rebuild, and deploy**. בהפעלה השרת רושם את ה-webhook אצל טלגרם לבד. ב-**Logs** צריכה
   להופיע השורה `Telegram: webhook registered at https://<service>.onrender.com/webhooks/telegram`.

## 3. ה-chat id שלך
1. בטלגרם פותחים את הבוט החדש ושולחים `/id`.
2. הבוט עונה במספר (למשל `555001234`). `/id` עובד לזרים רק כל עוד `TELEGRAM_ALLOWED_CHAT_IDS`
   ריק (מצב הקמה). אחרי שממלאים אותו, הבוט לא עונה לאף צ'אט אחר.
3. ב-Render מוסיפים:

   | Key | Value |
   |---|---|
   | `TELEGRAM_ALLOWED_CHAT_IDS` | המספר שקיבלת. כמה צ'אטים: מופרדים בפסיקים |

   קבוצה (id שלילי) ברשימה = כל חבר בקבוצה יכול לשלוח משרות ולצרוך את מכסת Gemini. עדיף צ'אט פרטי.

4. שוב **Save, rebuild, and deploy**.

## 4. בדיקה
שולחים לבוט `/start` (מסביר מה לעשות), ואחר כך הודעה עם קישור למשרה. צריכה לחזור תשובה
"קיבלתי 1 משרות חדשות", ואחרי כדקה-שתיים הציון. המשרה מופיעה גם בדשבורד.

## תקלות
ב-Render ← **Logs**:

| מה רואים | הסיבה |
|---|---|
| `no RENDER_EXTERNAL_URL - webhook not registered` | השרת רץ מקומית. בטלגרם webhook דורש כתובת HTTPS ציבורית |
| `Telegram: setWebhook failed (401)` | הטוקן לא נכון (העתקה חלקית?) |
| `not in TELEGRAM_ALLOWED_CHAT_IDS` | המספר לא תואם. מוחקים זמנית את `TELEGRAM_ALLOWED_CHAT_IDS`, פורסים, ושולחים `/id` שוב |
| `sendMessage failed (403)` שחוזר | חסמת את הבוט בטלגרם. הציון ינוסה שוב עד 48 שעות ואז ייזנח |
| `401` על `POST /webhooks/telegram` | הטוקן הוחלף אחרי שה-webhook נרשם: פריסה מחדש רושמת אותו שוב |
| הבוט לא עונה בכלל | השירות ישן (Render החינמי): ההודעה תגיע כשהוא יתעורר, טלגרם שומרת עדכונים עד 24 שעות |

## מגבלות (מהתיעוד של טלגרם, 2026-11-26)
- הבוט חינמי (https://core.telegram.org/bots/faq).
- עד הודעה אחת בשנייה לאותו צ'אט. הודעה עד 4096 תווים (הבוט מקצר אם צריך).
- הציון נשלח עד 48 שעות מההודעה שלך. אחרי זה ההתראה נזנחת (המשרה נשארת בדשבורד).
- Render החינמי ישן אחרי 15 דקות. הודעה בזמן השינה מעירה אותו: טלגרם שולחת שוב עד שמקבלת תשובה,
  כך שלא הולך לאיבוד, אבל התשובה הראשונה יכולה לקחת דקה ויותר.
